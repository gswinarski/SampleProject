# Case handling and escalation

Fictional project process. It does not describe a configured Salesforce organization.

## Process flow
The agent records a Case, assesses its priority and assigns it to a specialist. The specialist resolves the case.

## Assumptions
This simplified variant shows the escalation path. Handling without escalation is outside the diagram’s scope.
